Recuperar clientes desde las facturas

Esta herramienta reconstruye la base de clientes del usuario actual usando únicamente la información almacenada en sus facturas. No modifica las facturas.

Antes de restaurar se guardará una copia de seguridad de la base de clientes actual en este mismo navegador.
